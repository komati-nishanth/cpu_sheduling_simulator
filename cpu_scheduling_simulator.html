    Lab procedure

    Aim: To simulate the CPU scheduling algorithms FCFS, SJF, SRTF, Round Robin and Multilevel Feedback Queue, draw the Gantt chart, and calculate completion time, turnaround time and waiting time for each process.

    Formulas:
    Turnaround time (TAT) = Completion time (CT) − Arrival time (AT)
    Waiting time (WT) = TAT − Burst time (BT)

    Algorithms in brief:

    • FCFS: the process that arrived first runs first, to completion.
    • SJF: among waiting processes, the shortest burst runs next, to completion.
    • SRTF: like SJF, but a new process with less remaining time preempts the running one.
    • Round Robin: each process runs for at most one time quantum, then goes to the back of the queue.
    • MLFQ: several queues with different priorities; processes that use their full quantum move to a lower queue.
    FCFS / SJF (non-preemptive)
  t = 0; done = 0
  while done < n:
      pick = none
      for each process i not finished with AT[i] <= t:
          FCFS: choose smallest AT      SJF: choose smallest BT
      if pick = none: t = t + 1; continue      // CPU idle
      t = t + BT[pick]
      CT[pick] = t; mark pick finished; done = done + 1
  for each i: TAT[i] = CT[i] - AT[i]; WT[i] = TAT[i] - BT[i]

ROUND ROBIN (quantum Q)
  queue = processes with AT <= 0; t = 0
  while processes remain:
      if queue is empty: advance t to next arrival; add arrivals; continue
      p = dequeue()
      run = min(Q, rem[p]); t = t + run; rem[p] = rem[p] - run
      add every process with AT <= t that is not yet queued
      if rem[p] > 0: enqueue(p) else CT[p] = t

SRTF
  at every instant, run the arrived process with the least remaining time;
  re-check whenever a new process arrives or the running one finishes

MLFQ
  Q0 (quantum 2) -> Q1 (quantum 4) -> Q2 (FCFS)
  always serve the highest non-empty queue
  if p uses its full quantum: move p down one queue
  if p is preempted by a Q0 arrival: p goes to the back of its own queue

    What is the difference between turnaround time and waiting time?

    Turnaround time is the total time from arrival to completion. Waiting time is the part of that time the process spent in the ready queue, so WT = TAT − BT.

    Why can FCFS give a long average waiting time?

    A long process at the front makes every process behind it wait. This is called the convoy effect.

    Which algorithm gives the minimum average waiting time?

    SRTF is optimal for average waiting time. Non-preemptive SJF is optimal among non-preemptive algorithms. Both can starve long processes.

    How does the time quantum affect Round Robin?

    A very large quantum makes RR behave like FCFS. A very small quantum causes many context switches and wastes CPU time.

    What does an idle block in the Gantt chart mean?

    No process has arrived and the ready queue is empty, so the CPU waits until the next arrival.

    Why does MLFQ move processes between queues?

    Short and interactive jobs finish in the upper queues. Long CPU-bound jobs sink to lower queues, so short jobs get good response time.

    What is starvation and how can it be reduced?

    Starvation is when a process waits indefinitely. Aging, which raises the priority of long-waiting processes, reduces it.
